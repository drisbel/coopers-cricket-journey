# Cooper's Cricket Journey

Personal junior cricket career tracker for Cooper at Donnybrook Cricket Club.

## Prototype
- Mobile-friendly career dashboard, match history and manual match entry
- Light and dark themes
- Basic batting scorer
- Browser-local storage and data backup/export

**Not yet connected to Google Sheets.** Scores saved on one browser are not shared across devices. Secure editor login and full ball-by-ball scoring are planned.

## Publish
GitHub repository Settings → Pages → Deploy from a branch → main / (root).
